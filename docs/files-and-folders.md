# Files and Folders

## Purpose

Files and folders organize the local MyBook workspace.

## File Types

MyBook supports:

- document
- spreadsheet

New files start as local IndexedDB records with pending sync status.

## File Actions

Users can:

- create
- open
- rename
- duplicate
- move
- delete to Trash
- restore from Trash
- permanently delete

Deleted files are hidden from normal views and shown in Trash.

## Folder Actions

Users can:

- create folders
- browse child folders
- rename folders
- delete folders

Folder nesting is limited to three levels.

Deleting a folder also marks child folders and files as deleted locally.

## Search

The Search page finds files by name. It supports:

- filtering by type
- sorting by recent, oldest, name, or type
- file actions directly from results
